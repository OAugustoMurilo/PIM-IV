## NexHelp (Ionic + Angular)

Aplicativo móvel híbrido construído com Ionic Framework e Angular para consumir uma API em C#.

- **Instalação:** `npm install`
- **Execução web:** `ionic serve`
- **Execução em dispositivo:** `ionic capacitor run android` ou `ionic capacitor run ios`
- **API base:** configure o endpoint em `src/environments/environment.ts`
- **Serviços:** utilize `ApiService` para chamadas HTTP e mantenha os módulos organizados em `src/app`
